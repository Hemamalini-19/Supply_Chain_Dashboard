# 📊 BMW Logistics KPI Dashboard

## 🎯 Project Objective
Automate the detection of shipping delays to optimize material steering. This tool provides data-driven insights to minimize logistics errors.

## 🛠 Skills & Tools
- **Preprocessing:** Cleaning large logistics datasets and handling datetime transformations.
- **Algorithms:** Developed a classification logic to flag late shipments.
- **Reporting:** Automated KPI generation for supply chain stakeholders.
- **Stack:** Python (Pandas, Matplotlib), GitHub, Google Colab.

## 📈 Key Result
Identified high-variance regions in the global supply chain, allowing the logistics team to prioritize routes with >15% delay rates.
